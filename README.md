# Sado

**Sado** ("voice" in Tajik and Uzbek) is a voice-first AI assistant for Tajik and Uzbek speakers, built on Meta's Muse models.

Built for the **Meta Global AI Developer Hackathon** (Oct 26 – Nov 4, 2026), Indie track.

## What it does

- Talk to the assistant in Tajik or Uzbek.
- Photograph a letter or official document and get it explained in plain language.
- Set reminders and draft replies through tool calls.
- Hear the answer spoken back in your own language.

## Stack

- **Mobile app:** Flutter
- **Brain:** Muse Spark via Meta Model API
- **Speech:** Muse Voice Transcribe, Tajik/Uzbek text-to-speech
